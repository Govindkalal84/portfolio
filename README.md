## Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+), Tailwind CSS, React.js
* **Backend**: Java, Spring Boot, Hibernate JPA, REST APIs
* **Database**: SQL Databases
* **Interactions**: HTML5 Canvas Particle System, Custom Transitions, responsive CSS grids

## Local Setup
To run this project locally:
1. Clone this repository:
   ```bash
   git clone https://github.com/Govindkalal84/Portfolio.git
   ```
2. Navigate to the directory and double-click `index.html` to launch it in any web browser.
